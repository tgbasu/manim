# PredictionPipeline narration

Record this script as `assets/audio/PredictionPipeline.wav`. Aim for roughly
20–25 seconds, leaving pauses as the animated packet moves between cards.

“Data in. A prediction out. But what happens inside? Start with an input of two.
Our simple model multiplies that input by two, then adds one. The result is five.
That's inference: using a model to make a prediction. Training is the step that
learns the model's parameters from data. Different models have different rules,
but this input, model, output pipeline is a useful starting point.”

The scene runs about 22 seconds. Align narration to the visual beats; use
`--voiceover-offset` for an opening pause. Longer narration holds the last frame,
so edit animation timing when the speech needs more time during an earlier beat.
